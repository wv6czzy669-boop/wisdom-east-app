# App Store Metadata — ZH-HANT

Locale: Traditional Chinese (`zh-Hant`)

## APP NAME

EAST.

## SUBTITLE

寂靜發聲之處

## PROMOTIONAL TEXT

一則智慧，接著留白二十四小時。可以珍藏、寫下反思，也可以讓它靜靜經過。

## DESCRIPTION

每天，留一個安靜片刻。

停一停。
感受。
由心而問。

短暫停頓後，EAST.呈現一則智慧。下一則出現之前，留下二十四小時的空白。沒有動態牆，沒有連續紀錄，也沒有滑不完的內容。

若一則智慧留在心裡，可以將它珍藏。寫下私密的反思，重讀珍藏的內容，並把留下的片段收進日記。

EAST.支援15種語言。

每日儀式可免費使用。「珍藏」是選購的一次性購買項目，可移除珍藏與反思的數量限制、啟用日記PDF匯出，並支持EAST.。它不會解鎖額外的每日智慧。
