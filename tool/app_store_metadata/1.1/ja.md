# App Store Metadata — JA

Locale: Japanese (`ja`)

## APP NAME

EAST.

## SUBTITLE

静けさが語る場所

## PROMOTIONAL TEXT

一つの気づき。そのあとには24時間の余白。心に留めても、内省を記しても、ただ見送っても。

## DESCRIPTION

毎日、静かなひとときを。

立ち止まる。
感じる。
心から問いかける。

短い間を置いて、EAST.は一つの気づきを届けます。次の気づきが現れるまで、そこには24時間の余白があります。フィードも、連続記録も、スクロールするものもありません。

心に残った気づきは、そっと残しておけます。自分だけの内省を書き、残したものを読み返し、日記にまとめられます。

EAST.は15の言語で利用できます。

毎日の静かなひとときは無料です。「残す」は、気づきの保存と内省の記入にある制限をなくし、日記のPDF書き出しを利用できるようにしてEAST.を支える、任意の買い切りです。毎日の気づきが増えることはありません。
