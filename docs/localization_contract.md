# EAST. localization contract

Meaning outranks literal wording. Future wisdom review prioritizes: core meaning fidelity; theological and emotional safety; natural native expression; EAST. tone; visual footprint; literal similarity.

Translations must not become more mystical than their English source, add direct you/your address, advice, claims, or metaphysical certainty. Use a natural neutral equivalent for God; Turkish uses **Tanrı**, never Allah. Metaphors may adapt only when meaning remains intact. UI terminology receives separate brand-language review. Never auto-shrink typography to rescue a translation.

## Keeper brand

Keeper is the purchase name in every product locale. Preserve the exact name
`Keeper` in headings, access states, purchase/restore guidance, upgrade actions,
and the native widget gate. Localize the surrounding sentence naturally; do not
translate the name into a verb such as “Tutucu”, “Bewahren”, or “Guardar”. This
does not change ordinary keep/save verbs or the existing Kept, Reflection, and
Journal terminology.

Keeper previews are clearly labelled examples using one fixed catalog wisdom
and an illustrative reflection. They never read personal writing, select a new
wisdom, or change the rolling 24-hour ritual. Preview copy and the three-step
widget guide must have complete translations in all 15 product locales.
